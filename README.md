# HW2
## Devlog
The classes I had planned were the player class, the coin, and the UI. In reality I had classes for the player, the coin spawner, the coin itself, and the UIManager. I used methods like OnTriggerEnter2D so that when the player touches a coin, it will disappear and tell the UIManager to update the text to add one point to the player's points.
